## 1. 推荐题目

**面向多领域多模态时间序列预测的频率感知语义专家融合方法**

英文工作名：**FAME-TS: Frequency-Aware Multimodal Expert Fusion for Time Series Forecasting**。

## 2. 研究对象与任务

给定长度为 \(L\) 的多变量历史序列 \(\mathbf X\)、与该时间区间对齐的文本集合 \(\mathcal T\) 以及预测跨度 \(H\)，预测未来目标序列：

\[
f_\theta:(\mathbf X_{t-L+1:t},\mathcal T_{t-L+1:t},H)
\mapsto \hat{\mathbf Y}_{t+1:t+H}.
\]

主任务采用 Time-MMD 中真实对齐的数值与文本数据，优先覆盖 Energy、Climate、Economy 和 Traffic。各领域的采样频率和标准预测跨度以原始数据审计及官方基准为准，不强行统一成 ETT 的 \(96/192/336/720\)。

## 3. 核心假设

1. 外生文本只在部分时间段携带增量信息。
2. 文本事件可能主要影响高频短期扰动或低频长期趋势。
3. 文本价值随预测跨度、文本覆盖率和领域变化。
4. 静态融合会在无关或滞后文本出现时产生负迁移。

## 4. 模型结构

### 4.1 数值时域专家

使用轻量 Patch/线性骨干提取局部变化、趋势和变量依赖，输出数值基线预测及表示 \(\mathbf Z_t\)。

### 4.2 频域专家

对窗口执行 rFFT，将频谱划分为低频和高频表示，并学习频带权重：

\[
\mathbf Z_f=\operatorname{Encoder}_f(\operatorname{rFFT}(\mathbf X)).
\]

### 4.3 文本语义编码

使用冻结的小型文本编码器。文本嵌入离线预计算并缓存，降低显存和训练成本。训练前审计文本时间戳、覆盖率、重复率及是否包含未来事实。

### 4.4 频率感知跨模态交互

文本分别与低频、 高频表示交互，得到文本对不同时间尺度的相关性分数。无文本窗口使用显式缺失掩码，不把空文本编码成普通语义。

### 4.5 动态专家融合

门控网络根据数值表示、文本质量特征和预测跨度，在数值专家、低频语义专家和高频语义专家之间分配权重：

\[
\boldsymbol\pi=\operatorname{softmax}
\left(g_\phi(\mathbf Z_t,\mathbf Z_f,\mathbf z_{text},H,\mathbf q_{text})\right),
\]

\[
\hat{\mathbf Y}=\sum_k\pi_k\hat{\mathbf Y}^{(k)}.
\]

其中 \(\mathbf q_{text}\) 包含文本是否缺失、文本数量、时间距离等质量特征。

## 5. 基线

- Last Value / Seasonal Naive；
- DLinear；
- LSTM；
- PatchTST 或 iTransformer；
- 数值骨干 + 简单文本拼接；
- 数值骨干 + 固定加权晚期融合；
- 代表性多模态方法（在复现成本验证后从 TimeCMA、CALF、MM-TSFlib 中选择一个）。

## 6. 实验设计

### 主实验

- 数值单模态与多模态比较；
- 多领域、各领域标准预测跨度；
- 3 个随机种子；
- MSE、MAE为主指标。

### 消融

- 去掉频域专家；
- 去掉文本专家；
- 去掉文本质量特征；
- 固定融合替代动态路由；
- 去掉预测跨度条件；
- 去掉对齐/一致性辅助损失。

### 关键验证

- 10%/20%少样本；
- 文本随机打乱、文本时间错位、无关文本注入；
- 数值噪声、连续缺失和异常尖峰；
- 参数量、显存、训练和推理时间；
- 门控权重随领域、预测跨度和事件类型的变化；
- 典型成功/失败案例。

## 7. 数据泄漏防线

1. 严格按时间划分。
2. 标准化仅拟合训练段。
3. 文本只允许使用预测起点之前已经发布的内容。
4. 删除或屏蔽包含预测区间真实结果的摘要、回顾和未来时态标签。
5. 文本编码器缓存按数据划分生成并保留时间戳审计表。
6. 调参只看验证集，最终测试集只用于锁定模型后的评估。

## 8. 降级路线

若第 3 周数据审计发现 Time-MMD 的真实文本覆盖或时间对齐不满足要求，则转为 ETTh1/ETTh2 的“时频双分支 + 预测跨度门控”方案。降级只移除不可靠文本模态，保留完整基线、消融、鲁棒性、效率和原型交付，不降低课程质量标准。

## 9. 第 3 周验证门槛

在技术方案正式提交前必须完成：

1. 下载并读取至少一个 Time-MMD 领域；
2. 输出数值和文本时间覆盖、样本量及对齐率；
3. 运行 Seasonal Naive 与 DLinear 最小基线；
4. 确认一轮训练耗时和显存；
5. 检查文本是否包含未来信息；
6. 据此冻结最终数据集和模型范围。
