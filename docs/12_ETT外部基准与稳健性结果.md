# ETT 外部基准与稳健性结果

## 1 外部数值基准

ETTh1 和 ETTh2 均使用官方固定前 14,400 个小时。划分边界为训练 8,640、验证 2,880、测试 2,880；输入长度固定为 96，预测跨度为 96、336 和 720。所有模型接收多变量输入，只预测 OT 单目标。数值标准化仅使用训练段统计量。

PatchTST-M 在六项任务中全部取得最低平均 MSE，相对各任务最强非 PatchTST 基线的平均改善为 12.6883%。逐任务改善为：ETTh1 的 6.927%、12.362% 和 27.729%，ETTh2 的 0.861%、7.130% 和 21.121%。深度模型均使用 2026、2027、2028 三个随机种子。

这些结果只证明本项目实现的 PatchTST 数值骨干在当前单目标协议下有效，不能与文献中多通道平均指标直接比较，也不能写成跨数据集普遍优越。

## 2 输入扰动稳健性

稳健性实验保持模型参数冻结，对测试输入施加四类扰动：标准差 0.10 的高斯噪声、10% 随机缺失、末端连续 12 步缺失、2% 概率的正负 3 个训练标准差尖峰。缺失值在窗口内前向填补，首步缺失才填零。随机扰动使用 31、37、43 三个种子，并与三个 PatchTST 模型种子交叉组合。

PatchTST 在六项任务上的平均相对 MSE 退化为：高斯噪声 3.3107%，随机缺失 1.6770%，末端缺失 24.5883%，尖峰污染 84.3789%。因此，模型对轻度分散扰动较稳，但对局部极端值和最新观测连续缺失敏感。该结论将作为局限和后续异常值抑制模块的直接依据。
