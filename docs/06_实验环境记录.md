# 实验环境记录

## 当前验证环境

- 操作系统：Windows；
- Python：3.12；
- GPU：NVIDIA GeForce RTX 5070 Laptop GPU，显存 8151 MiB；
- NVIDIA 驱动：616.64；
- PyTorch：2.8.0+cu128；
- PyTorch CUDA Runtime：12.8；
- NumPy：2.2.6；
- Pandas：2.3.2；
- Scikit-learn：1.7.1。

## 已完成验证

1. `torch.cuda.is_available()` 返回 `True`；
2. PyTorch 正确识别显卡名称；
3. 已在 GPU 上完成 2048×2048 随机矩阵乘法并同步返回结果；
4. 审计脚本与确定性基线脚本的自检均通过。

## 复现约定

- 项目使用根目录下的独立 `.venv`，不依赖系统 Python 中的临时包；
- 精确直接依赖记录于 `requirements.txt`；
- 训练代码固定 Python、NumPy 和 PyTorch 随机种子；
- 数据加载暂设 `num_workers=0`，减少 Windows 多进程引入的复现差异；
- 每次正式实验保存配置、模型、训练日志、逐样本预测和汇总指标；
- 最终提交前将在干净环境重新安装依赖并执行统一复现入口。

## 显存约束

可用显存约 8GB，因此文本编码器采用冻结、离线缓存策略。主预测模型不端到端微调大型语言模型；这既控制资源，也有利于把性能变化归因于融合方法而不是额外的大规模参数。
