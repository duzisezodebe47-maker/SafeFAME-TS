## 4. 仍然存在的风险

1. v3为已查看测试期间后的纠错，v4也来自同一Time-MMD历史快照，不是新的独立未见验证。
2. `end_date`只是可得时间代理，真实发布时间未逐条核验。
3. 低频长跨度任务的决策块数有限，滚动折共享历史，不能把任务—折数量当成独立样本量。
4. 等宽纯数值对照只匹配输入宽度，不匹配有效秩和归纳偏置；质量特征的改善限制了纯语义归因。
5. 前沿文献用于方法定位和未来工作，未在同一数据和计算预算下与SafeFAME-TS直接比较。
6. 当前仅交付DOCX；最终PDF仍需在用户确认定稿后统一导出并再做页面一致性检查。
