# SafeFAME-TS 最终检查报告

检查日期：2026-09-16

## 1. 交付范围

本项目按个人课程设计完成，不制作或提交 PPT。正式报告覆盖问题描述、数据处理、系统与实验设计、算法原理、参数求解、基线比较、反事实检验、冻结确认、稳健性分析、结论与局限；支撑材料包含源代码、过程文档、关键中间数据、逐任务结果、图表和复现说明。

## 2. 题意与研究闭环

- 研究问题明确：检验文本在何种条件下有助于时间序列预测，并在文本无益时安全回退。
- 数据证据、模型方法、输出结果和验证方式在报告中逐项对应。
- 先建立传统与深度数值基线，再进行时点严格对齐的文本融合；使用随机置换文本反事实排除伪增益。
- 验证期按时间对半为校准段与独立路径决策段，测试集在全部选择冻结后使用。
- 结论直接回答研究问题，未将相关关系表述为因果关系，未声称文本普遍有效。

## 3. 数据与模型检查

- Time-MMD 文本仅使用事实字段，排除预测字段；要求事实结束时间严格早于预测起点。
- 文本索引含 14,281 条去重事实；report 与 search 各形成 384 维句向量，拼接后原始语义输入为 768 维，再在训练期内做 PCA 降维。
- ETT 外部基准含 ETTh1、ETTh2 与 96、336、720 三个预测跨度。
- 深度模型使用 2026、2027、2028 三个随机种子；稳健性扰动使用独立种子并保留协议文件。
- 关键模型均有基线比较；多模态结论有 99 次逐行错位置换、999 次保留序列内部结构的循环移位置换、分段稳定性、匹配容量纯数值残差对照、移动块 Bootstrap 和安全回退证据。

## 4. 结果一致性检查

`src/verify_project.py` 已从最终 CSV 重新计算并核验报告中的关键数字：

- 主实验 18 项、文本候选 36 条；通过完整资格门槛 0 条，最终文本路径启用 0 项。
- 语义候选测试期点估计改善 13/18 项，其中 3 项移动块区间完全大于零、4 项完全小于零。
- 频率候选测试期点估计改善 8/18 项，其中 2 项区间完全大于零、3 项完全小于零。
- ETT 任务 6 项，PatchTST-M 获胜 6 项，相对最强非 PatchTST 基线平均改善 12.69%。
- PatchTST-M 在高斯噪声、随机缺失、末段缺失和尖峰污染下的平均退化分别为 3.31%、1.68%、24.59% 和 84.38%。
- 999 次循环移位置换下 36 条候选均未达到每任务 Bonferroni 阈值 0.025；结论与冻结协议一致。
- 相对匹配容量纯数值残差对照，仅 Climate H4、H12 两条语义候选的测试期区间完全大于零；9 条候选区间完全小于零，其余跨零。
- 路径决策段的 36 条候选中，32 条不足 3 个完整非重叠块；仅 4 条可给出近似最小可检测效应，范围为 26.6% 至 558.9%，因此“零放行”必须同时解释为严格门控与低统计功效下的结论。

核验结果：通过。

## 8. 审稿式边界

- 文本测试点估计在气候、交通、农业部分任务为正，但 Traffic 区间跨零，且所有候选均未通过验证期完整门槛；匹配容量对照还表明 Agriculture H12 的较大表面改善主要来自残差结构而非可识别的文本增量。创新主张是“反事实诊断与安全回退”，不是“文本普遍提分”。
- 主协议的 99 次逐行错位置换分辨率较粗且未保留局部时间依赖；新增 999 次循环移位仅作为敏感性分析，固定原校准正则系数，不回写冻结路由。
- `end_date` 仅作为可得时间代理，不能写成已经核验的真实发布时间。
- PatchTST-M 对轻度噪声和随机缺失较稳，但对尖峰污染与末段连续缺失敏感。
- 当前结论适用于本项目的数据范围、切分方案和模型规模；不外推为因果规律。
- 学号、姓名、班级等身份字段未由用户提供，报告未虚构；如学校模板强制要求，应在提交前据实补入。
