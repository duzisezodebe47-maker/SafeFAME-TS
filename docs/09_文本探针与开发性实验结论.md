# 文本探针与开发性实验结论

## 1. 实验定位

Climate、Energy、Economy 和 Traffic 已用于特征、门控与稳定性规则的开发，因此其 20% 末段结果只能称为开发性时序回测，不再声称为完全未见的确认性测试。

## 2. 已完成的三级文本对照

1. TF-IDF 探针：对比文本单模态、早期融合、真实对齐和分割内打乱文本。
2. MiniLM 探针：使用固定版本 `all-MiniLM-L6-v2` 对严格时点事实编码，文本向量保持归一化，只标准化质量特征。
3. FAME-TS 开发原型：对比纯数值、无频率语义、频率—语义交互及文本置换安慰剂，并以验证集校准分歧门控。

## 3. 可复核结果

- TF-IDF 早期融合在 Traffic H=6 上相对当时最强数值基线降低 MSE 4.21%，H=12 降低 0.97%。
- MiniLM 早期融合在 Traffic H=6 和 H=12 上分别降低 MSE 7.28% 和 4.81%；在其他开发领域上多数退化。
- Traffic 的真实对齐文本在三个跨度上均优于打乱文本；Climate、Energy 和 Economy 的该关系不稳定。
- 联合神经原型的验证均值较低，但在后期测试上出现明显负迁移；简单文本门控不能保证分布外安全。

## 4. 当前结论边界

现有证据支持“文本增益具有领域和预测跨度条件性”，不支持“多模态对所有时序都有效”。论文将把负迁移识别、文本置换对照和安全回退作为主要研究问题，而不夸大局部精度改善。
