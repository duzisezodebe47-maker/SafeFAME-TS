# v4 扩展滚动实验协议

用户已同意扩大实验并在完成后同步三份报告。配置在 `configs/safefame_v4.json`。本版是多领域历史滚动回测，不是未来数据的独立确认；上游最新提交经 GitHub API 核对仍为 00281e2d86058286d5548b15a7670e8eda57ef62（2025-01-14），未发现更新的 Time-MMD 时间段。40项指10组序列×4跨度，健康分US/AFR，领域口径为9个。各任务3个滚动折，共120个任务—折，不当成120个独立数据集。

## 数据规则

原始数据保留。AFR前三个缺失目标、SocialGood末尾八个缺失目标裁去；US五个冲突重复日期不能确定真值，两行折为一个未知观测，不猜测或平均成真值，原冲突行另存。任何目标跨度含未知值的窗口不用于拟合、选择或评价；输入协变量仅历史前向填充，再用训练期中位数补前导空值。时间顺序稳定排序。日频Environment保留日频，不通过重采样制造额外样本。每个窗口在同一数值时间段取历史fact，不使用pred/preds；文本end_date仍只是可得时间代理。旧MiniLM向量按稳定ID和文本一致性复用，仅编码新增文本，版本固定。

## 划分与模型

每个折的训练末端/校准末端/决策末端/测试末端比例依次为40/50/70/80%、50/60/80/90%、60/70/90/100%。每段只使用目标完全位于该段的预测起点；决策前后两半同样排除跨界目标。三折测试目标区间互不重叠；后折可以使用届时已观测的前折历史，属于滚动更新，不能称各折独立。保留五类专家、两类文本候选、原超参数范围及早停设置。深度模型5种子，模型选择基于种子平均预测。校准确定数值回退和残差正则；决策检验资格；保存选择记录之后才评价测试。重拟合只使用该折测试之前的完整已观测目标。

目标标准化使用已观测训练目标的均值和总体标准差；DLinear输入列使用因果填补后的训练列均值和总体标准差。存在未知观测时两者可不同，模型监督与所有损失评价仍统一使用前一种目标坐标。测试前重拟合不使用测试统计量；残差PCA与变换在完整测试前拟合集重估，初始目标尺度不改变。

## 检验与诊断

v4主门控为999次逐行文本/质量联合错位，各次重新校准α；仍要求总体和两个决策半段均优于数值回退，且经验p≤0.025。两候选的0.025只对应每个任务—折内的Bonferroni口径，不声称控制全部240条候选的家族错误率。另作999次循环移位敏感性，固定对齐校准α，结果不回写路由。5000次移动块Bootstrap仅为测试损失差诊断。各段内部重叠与相关性仍存在，块数仅是功效提示；更多重复次数不能创造新观测。历史输出字段`matched_*`实际对应纯数值残差消融：只保持Ridge模型家族和调参网格一致，输入维数不同，不能称为匹配容量或因果对照。

## 审查后归因补充

冻结v4之后新增`src/run_attribution_audit_v4.py`，只检查10条实际启用路线，不改变主路由。它分别拟合纯数值、质量特征、语义特征、完整特征和等维纯数值二阶段残差头；残差锚定该折实际回退预测，而非Last。校准段拟合、决策段选择Ridge正则，随后在校准加决策段重拟合并评价原测试段。等维数值对照使用固定种子的数值随机傅里叶特征，使设计宽度与完整候选一致，但不声称有效秩和归纳偏置完全相同。

频率候选的语义—频率交互尺度依赖行配对。原主实现将对齐训练数据拟合的交互标准化器复用于置换数据，优化实现和直接实现虽然一致，但这不能保证频率分支的严格交换性。新增诊断对唯一实际启用的频率路线逐次重新拟合交互尺度；逐行p从0.021变为0.085，循环p从0.060变为0.068。该结果属于审查后敏感性，不追溯改变已冻结选择，但限制该路线的归因解释。

另对240条已保存主门控p值作事后Holm与BH校正，并按任务族汇总跨折重复性；这些分析没有预注册，不能替代原逐任务门控或新增未来时间段确认。完整定义和结果见`docs/23_对照实验归因审计与修订.md`。

含未知目标的窗口剔除后，移动块及完整非重叠块数按保留起点的行顺序构造；缺口两侧的相邻保留行不一定在日历上连续。因此健康领域的块诊断还受缺口压缩影响，不解释为严格连续日历块下的功效保证。每项区间也未对240条候选进行同时覆盖校正。

## 执行与证据

先对短月频和长日频任务进行工程试跑，只检查运行、边界、算力和证据完整性，不根据试跑性能改变模型或阈值。正式运行前保存配置、代码、数据和缓存哈希；任务完成即保存逐起点预测、训练日志、模型权重、置换零分布、指标和文件哈希。断点恢复必须验证输入签名与已完成文件哈希，不覆盖已核验完成任务。最终验证从预测重新计算指标、路由和区间。汇总同时报告每折结果和每序列结果，跨序列比较相对改善，不直接平均不同标准化尺度的MSE。报告诚实保留负结果和低功效情形。

## 工程纠错记录

扩展新增H=1时，scikit-learn Ridge会将预测挤压成一维；旧多步残差辅助函数加上(n,1)的Last锚点会错误广播成(n,n)。随机多步自检未覆盖该情形，真实数据独立复核发现后已中断初始批次并移至tmp/v4_h1_shape_diagnostic，禁止进入正式统计。v4本地残差与纯数值对照均显式恢复(n,H)，增加H=1回归检查和评价形状断言；历史v2/v3没有H=1任务，源码和历史结果保持不变。重新冻结源代码签名后全量重跑。数值加速仍须通过直接sklearn拟合的真实数据对照；不通过不能发布。

新增健康领域预检查发现Health_AFR目标中另有3个无穷值，标准化断言停止运行。将所有无穷值明示转为未知观测，并沿用“不对未知目标监督或评价”的窗口排除规则，不以0或平均值代填。初始批次移至tmp/v4_nonfinite_input_diagnostic；为避免混合输入签名，全部120项重新运行，未复用该批次权重或结果。新增`--preflight`先覆盖所有120个任务—折的输入、目标、张量有限性与时间边界，再开始正式训练。处理前后数量及无穷值计数在numerical_audit.csv保留。

最终批次按固定任务分区运行到不同目录，以利用置换计算期间空闲的GPU：Environment的H1/H7共6折任务、其余领域108折任务、Environment的H14三折及H28三折，共四个独立进程。Environment原进程在H7第三折完整落盘后停止后续分配，可能刚开始的下一任务只归档，不进入统计；没有中断已纳入结果的任务。四进程使用同一配置、源代码和输入签名，随机状态彼此隔离；完成后仅汇入哈希核验通过的完整任务目录，并保留工作进程运行清单。没有同一目录的并发写入，也不按结果择优合并。

直接复算与缓存计算的float32 PCA矩阵乘法会因行排列产生舍入差异。Economy H1第3折实际完整重算两类999次主置换，语义零分布最大相对差约9.8e-6，频率约1.4e-6，p仍分别0.966与0.352。核验没有改写原结果：每候选每种分布先直接复算两次；若超出紧容差或p在[0.02,0.03]，则直接重算全部999次，要求经验p完全一致、分数相对偏差不超过1e-4（绝对容差1e-10），完整记录偏差。其他指标、路由和表格检查标准不变，不能以浮点误差为由略过门槛变化。
