# 目标边界修订协议

修订日期：2026-09-19。此文件在本轮修订实验运行前写入。研究问题、六领域、18项任务、数值专家、文本候选、外层70/10/20划分和测试区间不变。该测试期间已在历史研究中查看，本轮为审查后纠错复核，不能称为新增未见数据确认或前瞻性预注册。

## 版本和目标边界

历史v2按验证窗口起点对半，校准和决策目标存在H−1个时点重叠。原结果保留在outputs/safefame_v2，不能称其决策段目标完全未见。

v3将原始验证时间区间在floor((train_end+validation_end)/2)处分开。校准窗口要求origin+H≤boundary；决策窗口要求origin≥boundary，移除跨边界的H−1个起点。同一规则用于决策前后两个子段；若任一子段无完整窗口，分段稳定性不成立并回退。共享已经观测的历史输入是允许的；目标不交叉仍不等于时序统计独立。

## 求解和判定

新修订使用float64设计矩阵和统一Ridge cholesky求解器、固定BLAS/PyTorch计算线程1。历史v2仍保留lsqr实现用于回放，避免悄然改写原数值。三种子2026/2027/2028、原有调参网格、训练轮数上限和早停规则不变。

99次逐行文本/质量联合错位在每次校准重选α；总体胜出、两个目标不交叉子段均胜出、p≤0.025才可启用。999次循环移位仅敏感性分析，不改变99次路由；对齐与移位均采用相同求解器，α固定为对齐校准所选值。5000次移动块Bootstrap仅诊断测试损失差区间。

主行置换不保留时间依赖；循环移位还依赖局部平稳性与短样本限制。上述门槛是操作性筛选，不应宣称已经实证证明总体假阳性率控制。

## 保存与核验

outputs/safefame_v3保存逐任务原点、真实值、所有专家校准/决策预测、文本预测、99次错位分布、完整专家校准分数、种子早停日志与权重、回退重拟合权重与逐种子预测、运行前代码/数据/缓存哈希、线程环境。先保存本次冻结决策，再计算修订测试结果。数值门控与文本归因分别解释。

输出不得覆盖历史v2、旧999次敏感性或原始数据。修订结果无论正负均并列报告；不为保留旧结论而改阈值。
