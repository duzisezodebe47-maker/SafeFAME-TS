# SafeFAME-TS v2 冻结协议与结果

历史版本说明（2026-09-19）：以下数字原样保留。v2按预测起点对半，不是按预测目标完整隔离；18任务的校准与决策目标均有重叠，故不能称为独立资格确认。旧999次分析的对齐/移位求解器不同。纠错重跑单列于outputs/safefame_v3与两个修订敏感性目录，见docs/19、docs/20；不覆盖本文件的历史数字，也不宣称测试集在迭代开发中始终未见。

## 1. 冻结协议

- 时间划分：70%训练、10%验证、20%测试；历史v2把验证起点数组对半，存在H−1个目标时间点重叠。v3另按原始时间边界剔除跨界窗口。
- 数值专家：Last、SeasonalNaive、AR-Ridge、DLinear-M、PatchTST。
- 文本候选：语义残差、频率语义残差。
- 资格条件：候选在路径决策段总体优于校准选出的数值回退，且决策段前后两半均胜出，且 99 次文本置换检验经 Bonferroni 校正后 `p<=0.025`。
- 测试区间：逐预测起点配对损失的 5000 次移动块 Bootstrap，仅用于测试期区间诊断，不参与模型或路由选择。
- 随机种子：2026、2027、2028。

原始冻结协议使用99次逐行文本/质量特征联合错位置换。外部审查后新增999次循环移位置换敏感性检查，以保留每个数据段内部的文本时间结构；该检查只用于评估结论稳健性，不反向修改冻结的 v2 路由结果。

实现补记：资格判定前PCA及残差特征缩放仅拟合训练段；路由与超参数冻结后，在训练加验证段重拟合残差特征变换和模型。目标标准化仍沿用原始训练段参数。频率交互使用全部保留的语义主成分与前8个频率特征，非前8个语义主成分。

机器可读协议：`outputs/safefame_v2/safefame_v2_protocol.json`。

## 2. 关键结果

- 18 项领域—跨度任务、36 条文本候选路径。
- 6 条候选通过决策段前后两半稳定性，但 0 条通过 `p<=0.025` 的置换门槛。
- 最终 18 项任务均选择数值回退。
- 测试期事后诊断：语义候选 13/18 项点估计改善，其中 3 项移动块区间完全大于零，4 项完全小于零。
- 频率候选 8/18 项点估计改善，其中 2 项区间完全大于零，3 项完全小于零。
- 测试期事后优势不得用于返回修改验证门槛。

## 3. 解释边界

该结果说明在当前六领域数据、当前轻量文本表征和预先规则下，没有足够证据部署文本路径；不能解释为文本在所有时间序列任务中无效。原候选以 Last 为残差锚点，而资格判定相对于校准选择的数值回退，因此候选相对回退的点估计同时包含残差结构差异，不能单独归因为文本。文本相关增量应结合置换检验以及新增的纯数值残差消融对照解释。该对照保持Ridge家族和调参网格一致，但输入维数不同，不能称为严格匹配容量，也不能识别因果效应。验证样本较少和 `end_date` 仅为可得时间代理也是主要限制。
