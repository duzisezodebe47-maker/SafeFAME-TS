## 3. 预先规定的成功标准判定

六个扩展任务均未通过语义路径启用门槛，因此当时设定的“至少一个扩展任务改善”标准未达成；不将这些后来反复使用的任务称为全局未见任务。

选择器在6/6任务上回退，输出与内部数值路径一致；这些任务中完整候选测试MSE均更高。这是当前样本的描述性结果，不能据此保证新任务安全或证明因果伤害。

## 4. 分布漂移解释

- Agriculture 在训练和验证阶段没有 report 覆盖，而测试阶段 report 覆盖约 56%–60%，存在明显来源分布切换。
- Security 全时段没有 report，只有 search 事实；末段目标的归一化误差极大，表明其数值分布也发生强烈变化。
- 这些现象提示应考虑来源切换与数值漂移；本实验未单独操纵特征维度，不能证明扩大维度导致负迁移。

## 5. 论文中允许的主张

1. 严格时点代理约束和错位对照用于检查对齐敏感性，但不能识别真实因果信号或排除全部伪相关。
2. 文本收益在开发领域中只对 Traffic 的部分跨度出现，不具有跨领域普遍性。
3. 当次选择规则在六个扩展任务上回退，不能声称跨开发阶段测试完全未见或超越所有数值基线。
4. Security 的强漂移误差表明，当前方法的预测精度仍受制于数值分布外问题；安全回退只避免额外文本伤害，不会自动解决目标漂移。
