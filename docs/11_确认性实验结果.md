## 3. 预先规定的成功标准判定

六个未见任务均未通过语义路径启用门槛，因此“语义输入在至少一个新任务上提高精度”的确认性标准未达成。这是否定结果，必须在摘要、正文和结论中如实报告。

同时，选择器在 6/6 任务上拒绝了最终证明有害的语义路径，使 Selective 输出与内部数值路径完全一致。因此，“安全回退能避免未见任务上的文本负迁移”得到了本轮确认性证据。

## 4. 分布漂移解释

- Agriculture 在训练和验证阶段没有 report 覆盖，而测试阶段 report 覆盖约 56%–60%，存在明显来源分布切换。
- Security 全时段没有 report，只有 search 事实；末段目标的归一化误差极大，表明其数值分布也发生强烈变化。
- 上述结果说明，文本可用性、来源一致性与目标制度稳定性必须同时考虑，单纯扩大文本特征维度会放大负迁移。

## 5. 论文中允许的主张

1. 严格时点对齐和文本置换对照可以区分真实时序信号与模板/时间伪相关。
2. 文本收益在开发领域中只对 Traffic 的部分跨度出现，不具有跨领域普遍性。
3. 预先冻结的安全选择器在全部未见任务上避免了有害语义路径，但不能声称其超越所有数值基线。
4. Security 的强漂移误差表明，当前方法的预测精度仍受制于数值分布外问题；安全回退只避免额外文本伤害，不会自动解决目标漂移。
