# 课程要求与项目范围

## 1. 已确认要求

根据两页课程课件及老师最新通知，当前有效要求如下：

1. 项目改为个人完成。
2. 不需要制作和展示 PPT。
3. 第 1-3 周调研相关技术、论文、开源项目和代码，确定题目、问题、关键算法、改进路线和实验设计。
4. 课件分别出现“第 3 周提交”和“第 4 周提交”的表述。项目按更早的第 3 周准备，保留第 4 周作为修改缓冲。
5. 第 4-17 周完成算法实验或系统设计实现及实践报告。
6. 最终报告必须包含完整问题描述、系统或实验设计、算法设计、实验结果和分析图表。
7. 源代码、详细实验数据和过程资料作为附件保留。
8. 第 10 周不再进行 PPT 分享，但保留一次内部中期审查，检查数据、模型、结果和进度。

## 2. 项目理解

本课程设计不是只写文献综述，也不是只运行一个现成模型。每个核心结论必须形成以下证据链：

> 原题要求 -> 数据证据 -> 模型方法 -> 输出结果 -> 验证方式

最终研究闭环为：

> 问题分析 -> 数据审计 -> 基线 -> 主模型 -> 参数求解 -> 主实验 -> 消融/鲁棒性 -> 解释 -> 原型系统 -> 报告与附件

## 3. 规模控制

“规模稍大”体现在问题维度和验证完整性，而不是无差别堆叠模型：

- 多领域真实多模态数据；
- 数值、频域和文本三类信息；
- 多预测跨度；
- 数值基线、强时序基线和多模态基线；
- 消融、少样本、鲁棒性、效率和解释性实验；
- 可复现代码、实验台账和简单原型。

不把训练大型基础模型、复现全部论文或盲目跑满所有数据集作为必要目标。

## 4. 当前最佳方案

暂定研究问题：**真实文本信息在何种条件下能够改善多变量时间序列预测，频率感知和动态专家融合能否降低无关文本带来的负迁移？**

主数据候选为 Time-MMD，优先选择 Energy、Climate、Economy、Traffic 等具有不同文本密度和周期结构的领域。ETTh1/ETTh2 作为无外部文本的数值基准及降级方案。

## 5. 成功标准

1. 至少一个朴素基线、一个线性基线、一个强时序基线和一个多模态基线被公平复现。
2. 所有数据按时间划分；训练外信息不参与标准化、调参和特征选择。
3. 主模型的每个新增模块均有消融证据。
4. 主要结果使用至少 3 个随机种子，报告均值和标准差。
5. 文本模态必须通过覆盖率、时间对齐、重复率和潜在泄漏审计。
6. 报告中的数字可从保存的预测结果和配置重新生成。
7. 最终代码可从统一入口运行，图表由结果文件自动生成。

## 6. 尚需老师确认

- 最终截止日期；
- 报告模板和篇幅；
- 附件提交格式与大小限制；
- 是否要求可交互原型；
- 课程是否规定 AI 使用披露格式。
