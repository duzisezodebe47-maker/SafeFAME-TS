1. 打开 [`辅助电脑02交付01次/交付与待对接事项.md`](辅助电脑02交付01次/交付与待对接事项.md)，了解实际完成内容、运行结果、限制和待对接事项。

3. 在 [`辅助电脑02交付01次/evidence/`](辅助电脑02交付01次/evidence/) 核对本轮测试与审计证据。

本分支与 `main` 没有共同提交历史，不建议直接点击“比较与拉取请求”进行普通合并。主控应审阅本目录后，按协作方案选择性接收交付文件。大型原始数据、可重建缓存、虚拟环境和压缩包均未上传。
