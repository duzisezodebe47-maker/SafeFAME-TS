## 当前题目

**文本何时有助于时间序列预测？——面向多领域的严格时点对齐、反事实检验与安全融合**

方法名：**SafeFAME-TS v2**（Falsification-first Multimodal Time-Series Forecasting with Safe Fallback）。

## 核心研究问题

真实文本信息并非在所有领域和预测跨度下都同样有用。项目研究：在严格时点约束下，文本语义是否提供超过数值预测的增量信息，以及如何用独立验证段、文本置换检验和安全回退拒绝不稳定路径。

## 课程硬性要求

第 3 周前形成题目和初步技术方案。最终成果至少包括完整问题描述、系统或实验设计、核心算法原理、实验结果及分析图表、源代码、详细实验数据和过程资料附件。具体计划见 [课程要求与项目范围](docs/00_课程要求与项目范围.md)。

## 复现与核验

推荐在 Windows PowerShell 中运行。完整重训耗时较长；若只检查提交材料与关键数字是否一致，执行：

```powershell
.\.venv\Scripts\python.exe .\src\verify_project.py
```

按实验阶段复现时，依次运行数据审计与文本索引、数值专家、`src/run_safefame_v2.py`、`src/summarize_safefame_v2.py`、`src/run_reviewer_sensitivity.py`、ETT 外部基准与稳健性脚本。v2 使用 70% 训练、约 5% 校准、约 5% 路径决策、20% 测试；两个文本候选均须通过分段稳定性和 Bonferroni 后 `p<=0.025` 的置换门槛。随机种子、置换次数与区间设置见 `outputs/safefame_v2/safefame_v2_protocol.json`，外部审查后的循环移位、匹配容量对照和功效审计见 `outputs/reviewer_sensitivity/`。

## 决策门

冻结规则没有在 18 项 Time-MMD 任务中放行文本路径。测试期事后诊断显示语义候选在 13 项任务有正点估计，但这里比较的是完整残差候选与数值回退，不能直接解释为纯文本效应。匹配容量纯数值残差对照显示，只有 Climate H4 与 H12 的语义候选区间完全支持文本增量，9 条候选区间支持变差；999 次循环移位置换仍无候选达到 `p<=0.025`。最终结论是“当前证据不足则回退”，而不是“文本永远无效”。
