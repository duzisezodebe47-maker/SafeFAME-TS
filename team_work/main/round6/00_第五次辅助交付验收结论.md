## 数据接收范围与限制

主控接收报告为 `results/master_formal_bundle_audit.json`。Agriculture、Climate、SocialGood、Environment 分别有 357、1080、700、14301 个保留起点；`proxy` 和 `conservative_lag` 均可读取。SocialGood 的文本可用起点在两情景分别为 341、340；其它任务在交付数组中均为全量可用。这是接口和覆盖事实，尚非对文本来源真实性或外部泛化的证明。主控没有从原始 Time-MMD 全链重跑到清洗 CSV，下一轮由数据侧补来源与截止时间审计。

数据侧自己的 `transfer_receipt.json` 仍写 `MASTER_ACK_PENDING`，因为它发布时无法替主控确认。本文件及主控接收报告构成主控接收确认；数据侧下一轮应引用本次固定提交和报告哈希更新交接状态，不得改写旧 Release 附件或静默替换签名。

## 模型仍须修的接口问题

1. 模型 `predict_test.py` 的门控路由校验修好了候选旁路与两锚，但目前没有强制 `route.status == "frozen"` 及主控封印产物的来源字段。正式测试必须只接受主控公布的实际路由 SHA256 和封印字段，拒绝自行填写的旧 smoke 路由。
2. 数值回退测试路径仍把 test 段通过 `to_feature_bundle` 放入 `parts_all`，其 `targets_standardized` 随之进入 `numeric_baselines`。当前算法仅在 train/cal 用真值拟合及选 α，主控没有观察到目标泄漏；但“测试预测入口不给模型测试真值”的接口隔离仍未真正满足。应改成不含 test 目标的预测函数或独立无真值视图，再运行故障注入。
3. `--seasonal-period` 仍有默认值 12。其它任务应从冻结 spec 读取并强制与任务登记值一致，避免 Climate/Environment 在真实回退中误用 Agriculture 的周期。
