# 主控电脑第十轮任务

## 目标

在不提前暴露 SocialGood 测试信息的前提下，完成数据包验收、任务契约冻结和模型启动门控。

## 工作项

1. 等待 `3218151885-creator` 的第九次数据交付并固定提交 SHA。
2. 在只读副本中核对文件清单、哈希、边界、起点数量、时间顺序和文本覆盖率。
3. 独立复算窗口数量：24 步输入、3 步输出、周期 12；核对选择区 611、测试区 89 的预期是否与实际数据一致。
4. 检查训练区、选择区和测试区没有重叠，测试真值仅由主控持有。
5. 根据真实文本覆盖率决定候选注册表：
   - 覆盖充分：允许语义候选进入选择区；
   - 覆盖为零或过低：执行安全退化，不以多模态名义参赛。
6. 生成主控验收 JSON 和 SHA-256 清单，签发唯一可用的数据包标识。
7. 只有验收通过后，向模型电脑发布 SocialGood 正式训练指令。
