# Agriculture 独立测试结果

主控在路由封印后才读取 test 真值。评分对象为 42 个 origin、每个 12 步，共 504 个预测点。模型侧只提交 `N+S+Q+SF`，主控独立生成 AR-Ridge 测试预测。

## 结果

- AR-Ridge 标准化 MSE：0.4456405472。
- N+S+Q+SF 标准化 MSE：0.1893727828。
- 相对 MSE 下降：57.5055%。
- N+S+Q+SF 标准化 MAE：0.3585797561。
- 原始尺度 RMSE：AR-Ridge 12.40396，N+S+Q+SF 8.08587。
- 原始尺度 MAE：N+S+Q+SF 6.66275。
- origin 级胜率：41/42，即 97.62%。
- 配对损失改善为 0.2562677644；移动块 Bootstrap 95% 区间为 [0.2219551580, 0.3849859763]。

前半段和后半段分别下降 54.67% 与 60.16%；12 个预测步长均优于 AR-Ridge。因此该提升在当前测试段中具有时间一致性。

## 限制

该结果只适用于 Agriculture、fold 1、horizon 12 和 proxy 情景。文本发布时间是代理字段，原始 URL 未核验；结果不能解释为真实文本信息对农业价格的因果作用，也不能外推到其他三个领域。
