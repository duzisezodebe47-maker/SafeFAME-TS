### 但现有实现存在两个真实缺口

**缺口一：事后头的覆盖面与可比性**
`attribution_audit_v4` 的分支分离头**只覆盖冻结门控实际启用的 10 条路线**，且是**查看结果之后定义**的
二阶段分析（`docs/23:9`）。它们**没有**跑过冻结主门控（999 次逐行错位、每次重选 α、总体+两个
决策半段、p≤0.025）。因此**无法回答"若把这些分支分离候选作为正式候选，能否通过原定门槛"**。

**缺口二：现有的"分支分离"对线性模型是平凡的**
`ResidualBuilder.transform()` 把三个分支**拼成一个矩阵**喂给**单个 Ridge**：

```python
base = np.c_[numeric_scaled, PCA(embeddings, 24), quality_scaled]   # semantic_residual
```

对线性模型而言，`w·[a;b] ≡ w_a·a + w_b·b` —— **拼接与相加数学等价**。所以现有设计里
"分支"并没有真正隔离：它们共享同一个 α，且预处理尺度互相耦合。

### 1.2 新增（真正的工作量）

#### 新增点 A：**逐分支独立正则化的残差族**（核心结构）

这是对"分支隔离"的**可辩护实现** —— 因为对线性模型拼接等于相加，隔离必须体现在**正则化**上：

```
pred = Last  +  f_N(X_N)  +  f_Q(X_Q)  +  f_S(X_S)  +  f_F(X_F)
其中  f_b(X_b) = Ridge(α_b) 在 X_b 上的拟合
```

**与现有设计的实质差异**：

| | 现有 `semantic_residual` | 拟新增 |
|---|---|---|
| 分支预处理 | 三块拼接后统一标准化 | **每分支各自 fit/transform**，互不影响 |
| 正则化 | 单一 α 施加于全部特征 | **每分支独立 α_b**，各自在校准段选择 |
| 融合 | 隐式（矩阵拼接） | **显式可追溯**（各分支残差可单独取出检查） |
| 置换交换性 | 尺度重拟合需额外处理 | **按构造正确** —— 每分支尺度独立，置换时逐分支重拟合 |

**为什么这是新增而非换名**：单 α 与逐分支 α 施加的**正则化几何不同**。前者对全部特征施加同一
收缩强度，后者允许"语义分支强收缩、质量分支弱收缩"。这是可检验的归纳偏置差异，不是命名差异。

**代价**：逐分支 α 选择引入额外自由度。校准段选择需报告选择过程，并在敏感性分析中检验
α 网格细分是否会改变结论。

#### 新增点 B：**分支掩码语义的显式化**

任务书 §1.2 要求：`N+S` 中"**质量信息仅以必要掩码参与，不将质量特征悄悄混入语义分支**"。

现有实现做不到这点（质量总是拼进同一矩阵）。新增设计中：
- `N+S` 分支：`X_Q` **完全不进入**特征矩阵；仅当文本覆盖为零时，用掩码将 `f_S` 置零并回退
- `N+Q` 分支：`X_S` **完全不进入**
- 这是**结构性的**区分，不是特征子集选择

#### 新增点 C：**统一训练接口与可追溯融合**

一个可复用模块，实现：
- 统一读取 `FeatureBundle`（字段待主控冻结）
- 统一输出逐起点预测契约
- 融合函数显式、可单独调用、可追踪每分支贡献
- 逐分支的配置哈希与代码提交记录

## 2. 候选数学形式

所有候选共用：`pred = Last + Σ_b f_b(X_b)`，`f_b` 为对应分支上的 Ridge（cholesky 求解）。

| ID | 名称 | 分支组成 | 维度（L=输入长度） |
|---|---|---|---|
| C1 | `N` | `f_N` | L |
| C2 | `N+Q` | `f_N + f_Q` | L + 10 |
| C3 | `N+S` | `f_N + f_S`（Q 仅作掩码） | L + 24 |
| C4 | `N+S+Q` | `f_N + f_S + f_Q` | L + 34 |
| C5 | `N+S+Q+F` | `+ f_F`（含交互项） | L + 236 |
| C6 | `N+RFF` | `f_N + f_RFF`（宽度对照） | L + 24 |

**分支定义**：

| 分支 | 内容 | 维度 | 预处理 |
|---|---|---|---|
| `X_N` | 数值历史窗口 | L | StandardScaler（仅训练段 fit） |
| `X_S` | `PCA(24)` on `report⊕search` (768) | 24 | PCA 仅训练段 fit |
| `X_Q` | `QUALITY_NAMES` 质量特征 | 10 | StandardScaler（仅训练段 fit） |
| `X_F` | `frequency_statistics` | 10 | StandardScaler（仅训练段 fit） |

**注意 C4/C5 的定位**：它们**在维度上等同于现有 `semantic_residual` / `frequency_residual`**，
但**正则化结构不同**（逐分支 α）。若主控认为这构成"重复"，可降为敏感性分析，主候选改用现有实现。
